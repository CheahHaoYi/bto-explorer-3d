# Prices feature

Shows source-derived annual resale transaction medians for a selected HDB block when its exact block and street can be joined to the HDB footprint street code. Offline preparation is in `scripts/prepare_resale_history.py`; the static asset contract and provenance are documented in `docs/DATA_CONTRACTS.md` and `docs/DATA_SOURCES.md`.

The UI reports historical observations only. It does not estimate current value.
